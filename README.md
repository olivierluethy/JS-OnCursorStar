# Cursor Info Animate
This JavaScript code adds a number to the screen that follows the mouse cursor when it hovers over an element with the class “cursorInfoAnimate”. The number toggles between 0 and 1 and is displayed in a new <div> element that is created and appended to the selected element. The <div> element is removed after a delay of 750 milliseconds.

## Usage
To use this code, simply include it in your HTML file or JavaScript module. You can customize the appearance of the number by modifying the CSS properties of the “number” class.

## Dependencies
This code requires no external dependencies.
